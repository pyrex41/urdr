# M0 status

Status: adversarial verifier prototype; production integration pending

Agent 9 adds a self-contained negative/mutation harness for the semantic
nucleus. It is runnable before production modules are selected and does not
import, emulate, or certify those modules. Its provisional Python framing,
ordering, reducer, and PRNG oracles exist only to make attacks executable.

## Evidence available now

- Exact arbitrary-size integer round trips and noncanonical spelling rejection.
- Runtime-leak attacks for order, locale-like collation, and exception prose.
- Invalid UTF-8, duplicate-field, truncated, and over-limit fixture attacks,
  including every contiguous split of each short wire input and proof that
  rejected input causes no effect.
- Reducer purity, rollback, stale-ID, implicit-time, and tie-order attacks.
- Named PRNG path isolation, counter width, and bounded-draw bias-tail attacks.
- Fake adapter omission, alteration, reorder, downgrade, and invention attacks.
- Mutation checks showing that changing one fixture, required port, vector, or
  gate marker fails the self-contained gate.
- Optional read-only availability probes for the four required Shen launchers.

The exact commands and production integration seams are documented in
`shen/tests/adversarial/README.md`.

## Blocked claims

M0's selected canonical, UAP, reducer, PRNG, adapter-validation, and Bifrost
entry points are not present on the branch base. Consequently:

- launcher availability is not cross-runtime semantic agreement;
- Python prototype success is not Shen implementation evidence;
- provisional UAP framing/limits and the prototype PRNG vector are not
  normative fixtures;
- the M0 exit criterion remains unmet until at least three Shen ports produce
  byte-identical selected traces, vectors, verdicts, and replay output through
  the strict conformance gate.

This status makes **no whole-system D0, D1, or D2 claim**. M0 adversarial tests
cannot establish controlled guest boundaries, observable replay, device
scheduling, entropy-firewall coverage, executor capabilities, or certification.
